# Within- and Across-Age Residual Correlations of Growth Traits in Madura Cattle

This repository contains the [R analysis notebook](PDU_Madura_korelasi_english.ipynb) for body weight, body length, body height, and chest girth measured at birth, 6 months, 1 year, and 18 months. The notebook covers data checks, adjustment for sex and actual measurement age at postnatal stages, stochastic imputation of missing residuals, Pearson correlations, and GGally figures.

## Running the notebook

1. Open the notebook in Jupyter with the R kernel (IRkernel).
2. Install the R packages listed in the setup cell.
3. Set the `PDU_PROJECT_DIR` environment variable to the directory containing the input workbook required by the setup cell. The workbook is not included in this repository.
4. Run the cells in order.
